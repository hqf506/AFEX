# A2.4B.5E Operator Decision Checklist

The operator must record, without secrets or invented numbers:

- Approved isolated execution location: local controlled host or Vercel test deployment.
- Exact Node runtime and future reviewed dependency versions.
- Ordered HTTP, harness, checkout, statement, lock, transaction, and overall timeout budgets.
- Memory budget, pool maximum, expected concurrency, and database capacity allocation.
- Server-only secret scope, creation channel, rotation owner, emergency revocation owner, and expiry policy.
- Evidence directory, authorized readers, retention duration, deletion owner, and failure retention.
- Setup/cleanup operator, independent database reviewer, runtime reviewer, and final decision authority.
- Approved disposable owner strategy and response to partial setup/cleanup failure.

Every unresolved item is blocking. Approval of this checklist does not authorize SQL or harness execution.
