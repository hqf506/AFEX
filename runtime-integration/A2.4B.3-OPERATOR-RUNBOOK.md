10. Run the harness/controllers only in the isolated approved environment with bounded timeouts and complete stdout/stderr evidence.
11. STOP and quarantine on launch failure, assertion failure, unexpected SQLSTATE, missing evidence, timeout ambiguity, disconnect ambiguity, or nonzero exit.
12. Review evidence against the frozen schema. `INCOMPLETE` is blocking.
13. Run cleanup/revocation only through the separately approved provider-authority path. STOP if cleanup is blocked or ambiguous.
14. Run the read-only absence attestation and confirm no credential, session, membership, grant, owned object, or test artifact remains.
15. Obtain an independent final database/security/runtime review. No source result activates Core V2.

Provider ambiguity, missing operator input, hash mismatch, missing marker, partial setup, credential/session uncertainty, quarantine failure, and incomplete cleanup are mandatory STOP conditions. This runbook invents no authority to disable credentials or terminate sessions.
