# A2.3E Supabase Evidence Checklist

Record values only after applying the masking rules. A category describes the minimum acceptable source; it does not claim the field is present in the dashboard.

## Project and network

| Field | Evidence category | Safe value form |
|---|---|---|
| Project region | DASHBOARD_VISIBLE | Region label only |
| Compute tier | DASHBOARD_VISIBLE | Tier label only |
| PostgreSQL version | DASHBOARD_VISIBLE | Major/minor version |
| Project status | DASHBOARD_VISIBLE | Status label |
| Network restrictions | DASHBOARD_VISIBLE | Enabled/disabled and non-secret scope |
| IPv4 add-on status | DASHBOARD_VISIBLE | Available/enabled/not applicable |
| SSL enforcement | DASHBOARD_VISIBLE | Required/not required |
| Direct connection availability | DASHBOARD_VISIBLE | Yes/no |
| Direct host address family | DASHBOARD_VISIBLE | IPv4/IPv6/dual; no hostname |
| TLS mode and certificate requirement | DOCUMENTATION_REQUIRED | Mode/requirement labels |

## Capacity

| Field | Evidence category | Safe value form |
|---|---|---|
| Maximum database connections | DASHBOARD_VISIBLE | Integer |
| Currently used connections | DASHBOARD_VISIBLE | Integer and UTC time |
| Reserved/system guidance | DOCUMENTATION_REQUIRED | Numeric/reservation rule |
| Compute-specific connection limits | DOCUMENTATION_REQUIRED | Limit and tier |
| Statement timeout shown | DASHBOARD_VISIBLE | Duration or not shown |
| Idle transaction timeout shown | DASHBOARD_VISIBLE | Duration or not shown |
| Sustainable AFEX allocation | SUPPORT_CONFIRMATION_REQUIRED | Recommended integer |

## Connection methods

| Field | Evidence category | Safe value form |
|---|---|---|
| Direct connection format label | DASHBOARD_VISIBLE | Label only, no URL |
| Transaction pooler availability | DASHBOARD_VISIBLE | Yes/no |
| Session pooler availability | DASHBOARD_VISIBLE | Yes/no |
| Transaction pooler port | DASHBOARD_VISIBLE | Integer |
| Session pooler port | DASHBOARD_VISIBLE | Integer |
| Pool mode labels | DASHBOARD_VISIBLE | Transaction/session |
| IPv4/IPv6 compatibility per method | DOCUMENTATION_REQUIRED | Address-family labels |
| Vercel-recommended endpoint/mode | SUPPORT_CONFIRMATION_REQUIRED | Method and port only |

## Pooling semantics

| Field | Evidence category | Safe value form |
|---|---|---|
| Multi-statement transaction pins one backend | SUPPORT_CONFIRMATION_REQUIRED | Yes/no/conditional |
| `SET LOCAL ROLE` support | SUPPORT_CONFIRMATION_REQUIRED | Yes/no/conditions |
| `SET ROLE` support | SUPPORT_CONFIRMATION_REQUIRED | Yes/no/conditions |
| Dedicated custom LOGIN and SET-only membership | SUPPORT_CONFIRMATION_REQUIRED | Supported/unsupported/conditions |
| Prepared statement restrictions | DOCUMENTATION_REQUIRED | Supported mode/restrictions |
| Transaction advisory locks | RUNTIME_TEST_REQUIRED | Future observed result |
| Session advisory lock safety | SUPPORT_CONFIRMATION_REQUIRED | Prohibited/unsafe/supported |
| Session-variable behavior | DOCUMENTATION_REQUIRED | Reset/scope semantics |
| Cancellation behavior | RUNTIME_TEST_REQUIRED | Future observed result |
| Abrupt disconnect rollback | RUNTIME_TEST_REQUIRED | Future observed result |
| Backend reset/sanitation | SUPPORT_CONFIRMATION_REQUIRED | Guaranteed behavior |
| Role reset on return | SUPPORT_CONFIRMATION_REQUIRED | Guaranteed behavior |
| `current_user`/`session_user` reliability | RUNTIME_TEST_REQUIRED | Future observed result |
| Pool-size recommendation | SUPPORT_CONFIRMATION_REQUIRED | Numeric recommendation |

Any unavailable field is recorded as `UNKNOWN`, `NOT_AVAILABLE`, or the applicable escalation status; it is never inferred.
