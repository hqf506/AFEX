## Classification rules

- `RETAIN AS-IS`: compatible, bounded path with no present replacement need.
- `WRAP TEMPORARILY`: remains reachable only through a controlled compatibility
  boundary during migration.
- `REPLACE WITH CORE V2`: superseded by acquisition/executor/replay.
- `MOVE SERVER-SIDE`: browser or render mutation moves to authenticated server.
- `MOVE BEHIND RPC`: multi-write operation needs reviewed transactional database
  ownership.
- `REMOVE AS DEAD CODE`: only after evidence confirms no runtime dependency.
- `DEFER WITH EXPLICIT BLOCKER`: known requirement cannot proceed safely yet.
- `REQUIRES ADDITIONAL EVIDENCE`: current repository evidence cannot freeze the
  disposition.
