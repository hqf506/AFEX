# A2.3E Masking and Screenshot Rules

## Never collect

Passwords, database credentials, JWTs, API keys, service-role keys, access or refresh tokens, full connection URLs, certificate material, unnecessary private hostnames/project references, user identifiers, tenant/customer data, request payloads, or `.env` contents.

Safe examples are region labels, pool-mode labels, port numbers, yes/no capability states, numeric capacity, and `VARIABLE_NAME=SET|MISSING`. A connection URI is never safe evidence.

## Capture procedure

1. Open only the narrow provider subsection required by the checklist.
2. Hide browser password managers, address-bar query strings, developer consoles, notifications, account menus, and unrelated project data.
3. Prefer typed transcription. Use a screenshot only when provenance materially improves review.
4. Crop to the exact field before capture. Blur any remaining identifier; do not depend on blur where cropping is possible.
5. Inspect the image at full resolution before saving and again before sharing.
6. Record UTC capture time, provider, page/subsection, and environment separately.
7. Store locally in the approved evidence location; do not commit without a separate sensitivity review.

## Screenshot register

| Provider page | Subsection | Fields | Crop/blur | Preferred evidence |
|---|---|---|---|---|
| Supabase project settings | Infrastructure/general | Region, compute tier, status, PostgreSQL version | Crop project reference, organization, URLs | Transcription |
| Supabase database settings | Network/SSL | Restrictions, IPv4 status, SSL enforcement | Crop hostnames, strings, credentials | Narrow screenshot |
| Supabase connect panel | Connection methods | Method labels, modes, ports, address family | Crop username, hostname, database, complete URI | Transcription |
| Supabase usage/compute | Connections | Limits and current aggregate usage | Crop project/account identifiers | Narrow screenshot |
| Vercel project settings | Functions/runtime | Regions, runtime, Node version, duration, memory, compute mode | Crop team/project IDs | Narrow screenshot |
| Vercel environment variables | Scope matrix | Variable names and scope/presence only | Crop every value and secret control | Transcription strongly preferred |
| Vercel networking | Connectivity | Egress/private networking availability | Crop IP addresses and identifiers | Transcription |
| Vercel observability | Aggregates | Request, timeout, connection-error aggregates | Crop request bodies, user/tenant IDs, URLs | Narrow screenshot |
| Vercel deployments | Rollback | Rollback availability | Crop commit authors and unrelated URLs | Transcription |

Naming: `A23E_<provider>_<environment>_<page>_<YYYYMMDDTHHMMSSZ>.png`. Environment is `production`, `preview`, `development`, or `provider-general`.

## Rejection rules

Reject evidence that contains a secret, complete URL, private certificate, customer data, ambiguous environment, absent timestamp/provenance, unreadable masking, or a crop too broad to verify safely. Preserve only an incident note, not the unsafe artifact.
