# A2.4B.5E Evidence Domain Classification

| Domain | Classification | Reason / required proof |
|---|---|---|
| CREATE ROLE / LOGIN / ALTER ROLE authority | PROVABLE_BY_READ_ONLY_DATABASE_AUDIT; REQUIRES_SUPABASE_SUPPORT_CONFIRMATION; BLOCKING | Catalog attributes show apparent capability, but managed-platform permission and support require provider confirmation. |
| Password and expiry support | REQUIRES_SUPABASE_SUPPORT_CONFIRMATION; BLOCKING | Syntax support is not hosted-product approval. |
| Ownership transfer authority | PROVABLE_BY_READ_ONLY_DATABASE_AUDIT; REQUIRES_SUPABASE_SUPPORT_CONFIRMATION; BLOCKING | Membership/owner catalogs are necessary but cannot prove provider policy. |
| Schema/function creation authority | PROVABLE_BY_READ_ONLY_DATABASE_AUDIT; REQUIRES_OPERATOR_DECISION; BLOCKING | Effective ACLs and selected execution channel must both be known. |
| `afex_function_owner` existence | PROVABLE_BY_READ_ONLY_DATABASE_AUDIT | Exact role row and owned-object inventory. |
| `afex_function_owner` suitability | REQUIRES_OPERATOR_DECISION; BLOCKING | Security owner must approve blast radius. |
| Disposable owner strategy | REQUIRES_OPERATOR_DECISION; REQUIRES_SUPABASE_SUPPORT_CONFIRMATION; BLOCKING | Choose dedicated owner, justified existing owner, or reject mutation package. |
| Dashboard SQL editor authority | REQUIRES_SUPABASE_SUPPORT_CONFIRMATION | UI identity/capability is not safely inferred. |
| Direct psql authority | PROVABLE_BY_READ_ONLY_DATABASE_AUDIT; REQUIRES_OPERATOR_DECISION | Audit exact connected identity and channel. |
| Transaction Pooler endpoint/port | PARTIALLY_PROVEN; REQUIRES_SUPABASE_SUPPORT_CONFIRMATION | Port 6543 guidance exists; exact project endpoint remains external. |
| TLS/certificate behavior | REQUIRES_SUPABASE_SUPPORT_CONFIRMATION; BLOCKING | Must distinguish encryption from certificate/hostname verification. |
| IPv4/IPv6 | REQUIRES_SUPABASE_SUPPORT_CONFIRMATION; REQUIRES_OPERATOR_DECISION | Depends on provider project and execution host. |
| Current connection limits/usage | PROVABLE_BY_READ_ONLY_DATABASE_AUDIT | Catalog/settings and safe statistics only. |
| Safe pool budget | REQUIRES_OPERATOR_DECISION; REQUIRES_RUNTIME_TEST; BLOCKING | Requires capacity allocation and bounded load evidence. |
| Statement/transaction timeout budget | REQUIRES_OPERATOR_DECISION; BLOCKING | No numeric value may be invented. |
| Secret lifecycle | REQUIRES_OPERATOR_DECISION; REQUIRES_VERCEL_CONFIRMATION; BLOCKING | Scope, rotation, revoke, and emergency owner. |
| Evidence retention | REQUIRES_OPERATOR_DECISION; BLOCKING | Location, readers, duration, deletion. |
| Local versus Vercel execution | REQUIRES_OPERATOR_DECISION; REQUIRES_VERCEL_CONFIRMATION | Determines lifecycle and networking proof. |
| Advisory locks | REQUIRES_RUNTIME_TEST | Two-client transaction-scoped contention/release. |
| Cancellation | REQUIRES_RUNTIME_TEST | Separate controller and quarantine proof. |
| Abrupt disconnect | REQUIRES_RUNTIME_TEST | Child-process/socket termination and cleanup proof. |
| Unknown commit outcome | REQUIRES_RUNTIME_TEST | Harmless synthetic outcome and reconciliation controller. |

No external fact is classified as proven merely because PostgreSQL supports the underlying syntax.
