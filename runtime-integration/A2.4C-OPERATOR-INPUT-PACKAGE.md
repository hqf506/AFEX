# A2.4C Operator Input Package

Status: INPUTS REQUIRED; NO VALUES INFERRED

The accountable operator must record each item below without credentials or complete connection URLs. An unset item remains blocking.

| Input | Required recorded value / decision | Accountable role |
|---|---|---|
| Execution location | Controlled local host or isolated Vercel test environment; include network boundary and operator identity. | Platform owner |
| Node version | Exact approved major/minor/patch compatible with the reviewed harness. | Runtime owner |
| Dependencies | Exact approved `pg` and type-package versions, integrity source, lockfile procedure, and installation authorization. | Dependency/security reviewer |
| Timeouts | Numeric connect, checkout, statement, lock, transaction, controller, child-process, and overall-run limits with strict ordering. | Runtime and operations owners |
| Memory limit | Numeric process/container memory ceiling and failure action. | Platform owner |
| Pool size | Numeric maximum and minimum; must fit the approved database allocation. | Database and runtime owners |
| Concurrency | Numeric controller and overall concurrency ceilings. | Database and runtime owners |
| Pooler host suffix | Exact approved suffix, recorded without a full URL or credential. | Provider/platform owner |
| Port | Exact Transaction Pooler port. | Provider/platform owner |
| TLS mode | Exact mode, CA source, hostname-verification rule, and certificate-failure STOP behavior. | Security/platform owner |
| Credential creation | Identity authorized to create the disposable credential and the approved channel. | Security/database owner |
| Secret storage | Server-only scope, readers, injection method, and prohibition on logs/evidence. | Security owner |
| Rotation | Named owner and maximum lifetime/rotation procedure. | Security owner |
| Emergency revocation | Named owner, reachable channel, maximum response time, active-session action, and verification. | Security/database owner |
| Evidence retention | Local ignored root, authorized readers, retention duration, encryption/access controls, and deletion rule. | Governance owner |
| Cleanup | Named primary and backup owner, timing, partial-state procedure, absence attestation, and escalation authority. | Database/operations owner |

Approval of these inputs does not authorize dependency installation, SQL execution, credential creation, provider contact, or harness execution. Those remain separate gates.
