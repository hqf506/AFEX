### HIGH — getter-returned capability is not analyzed

- Path and lines: `scripts/check-core-v2-boundaries.mjs:484-497`.
- Issue: object callable registration handles `MethodDeclaration` and function-valued `PropertyAssignment`, but not `GetAccessorDeclaration`.
- Reproduced bypass: `const wrapper={get runner(){return client.query}}; export const run=wrapper.runner` produces zero findings.
- Violated contract: every statically resolvable returned forbidden capability must be rejected.
- Required correction: register getter-return provenance and property-read exposure with complete coordinates; add failing and harmless getter fixtures.
- Commit impact: blocks commit.

### HIGH — constant-computed method declaration names are unresolved

- Path and lines: `scripts/check-core-v2-boundaries.mjs:250-255,484-497`.
- Issue: method registration uses `staticName`; a computed name such as `[key]` resolves only when the expression is itself a literal, not when `key` is a compile-time constant.
- Reproduced bypass: `const key='getRunner'; const wrapper={[key](){return client.query}}; export const run=wrapper[key]()` produces zero findings.
- Violated contract: compile-time constant property resolution must be covered.
- Required correction: use the existing cycle-safe static-string resolver for computed declarations and preserve declaration/call coordinates; add literal, alias, enum, tuple/object-derived, and safe dynamic controls.
- Commit impact: blocks commit.

### HIGH — callable references stored in arrays/tuples are not propagated

- Path and lines: `scripts/check-core-v2-boundaries.mjs:504-575`.
- Issue: callable collection handles identifier and object paths but does not register array/tuple elements or resolve statically indexed callable paths.
- Reproduced bypass: `const f=function(){return client.query}; const methods=[f]; export const run=methods[0]()` produces zero findings.
- Violated contract: this review explicitly requires statically indexed array/tuple method references to be classified.
- Required correction: track immutable/static array elements and numeric element access through aliases, calls, and exports; retain unresolved dynamic indexes as a documented limitation.
- Commit impact: blocks commit.

### HIGH — static and inherited class method provenance is incomplete

- Path and lines: `scripts/check-core-v2-boundaries.mjs:552-564,583-588`.
- Issue: every class method is registered under `Class.prototype.method`; static methods are not registered under `Class.method`, and heritage is not propagated to statically constructed child instances.
- Reproduced bypasses: direct static method calls and inherited instance method calls each produce zero findings.
- Violated contract: A2.4A.7 explicitly requires static and inherited class methods to be tested, and statically resolvable bypasses must fail.
- Required correction: distinguish static/instance methods, propagate resolvable heritage, and add direct, aliased, inherited, overridden, and harmless fixtures.
- Commit impact: blocks commit.
