# A2.3E Provider Support Questions

Send no credentials, connection strings, project secrets, customer data, or unnecessary identifiers. Ask support to scope each answer to the applicable hosted product, plan, runtime, and current service version.

## Supabase Support

1. In transaction-pool mode, is one backend pinned for the whole explicit multi-statement transaction?
2. Can a `NOINHERIT` custom LOGIN execute `SET LOCAL ROLE` or `SET ROLE` within that transaction?
3. Is activated role state guaranteed to be removed when the transaction ends?
4. What cleanup occurs before the backend is assigned to another client?
5. Are transaction-level advisory locks supported with their PostgreSQL semantics?
6. Are session-level advisory locks prohibited or unsafe in transaction pooling?
7. Which prepared-statement modes are supported or restricted?
8. How does client or platform cancellation affect rollback and connection cleanup?
9. Does abrupt client disconnect force rollback before backend reuse?
10. Are `current_user` and `session_user` reliable throughout the pinned transaction?
11. Is a dedicated custom LOGIN with SET-only, non-INHERIT, non-ADMIN membership supported?
12. What hosted restrictions apply to custom PostgreSQL roles and memberships?
13. Which connection mode and port are recommended for Vercel serverless Node.js?
14. What maximum pool and connection allocation is recommended for this compute tier and workload?

## Vercel Support

1. Are outbound PostgreSQL TCP connections supported from the selected Production runtime?
2. Can warm instances safely reuse TCP connections and under what lifecycle guarantees?
3. What maximum per-instance database pool size is recommended?
4. How many simultaneous function instances may be created for the applicable plan and region?
5. What happens to open TCP connections during freeze, termination, cancellation, and redeployment?
6. Is a transaction-pool endpoint preferred over direct PostgreSQL for this runtime?
7. Are outbound IPv4 addresses stable, shared, or dynamic?
8. Are private networking or static-egress options available for this project?
9. How should database credentials be rotated without exposing them to Preview environments?
10. Is the Node.js runtime required for `pg`/node-postgres TCP connections?
11. What restrictions apply to long-lived connection pools in warm instances?

Record answers as provider-reported evidence, not runtime-tested proof.
