# A2.3H Future Test SQL Package Plan

Status: DESIGN ONLY — NO SQL CREATED

Each future file must be complete, independently reviewable, PostgreSQL-version compatible, fail closed, and manually executed only after approval. No password literal or secret may appear.

## Planned package boundaries

1. Test-role creation SQL
   - Preflight environment and namespace.
   - Create only dedicated NOLOGIN owner/execution roles with frozen attributes.
   - No business-object privileges.
   - Exact postconditions and rollback guidance.

2. Test LOGIN SQL
   - Create the restricted LOGIN without embedding a password.
   - Credential supplied through an approved out-of-band operator mechanism.
   - No ownership, inheritance, browser/service-role relationship, or business access.

3. Membership SQL
   - Exact LOGIN → test execution-role edge.
   - SET=true, INHERIT=false, ADMIN=false.
   - Reject every unexpected membership and grantor state.

4. Harmless test-function SQL
   - Fixed search path, narrow owner, catalog/constant-only behavior.
   - Return only identity, PID, transaction-safe diagnostic facts needed by the matrix.
   - No dynamic SQL, arbitrary role input, business table, P2D.20, network, or mutation beyond unavoidable test setup metadata explicitly reviewed.

5. Attestation SQL
   - Strictly read-only transaction ending in rollback.
   - Verify roles, memberships, ownership, ACL, RLS relevance, function signature/owner/search path/source hash, and absence of business access.

6. Cleanup/revocation SQL
   - Stop/revoke LOGIN, remove exact membership/ACL, drop only test objects/roles in dependency-safe order, and attest absence.
   - Fail on unexpected ownership, membership, session, lock, or dependency; never use broad cascade.

## Review sequence

Codex outputs each complete SQL artifact for independent review. The user returns it for review and executes it manually only after approval. Installation, test execution, and cleanup are separate controlled steps with separate evidence. Production business writes and P2D.20 calls are prohibited.
