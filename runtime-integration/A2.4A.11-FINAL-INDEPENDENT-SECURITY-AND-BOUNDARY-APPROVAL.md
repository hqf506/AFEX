## 5. Expression-normalization findings

## 6. Conditional/nullish findings

Direct conditional and nullish callable paths are conservatively merged, and compile-time booleans select the effective branch. However, when alternative container paths feed an array spread, the alternatives are treated as sequential sources. A safe-first/unsafe-second unresolved conditional spread therefore assigns the unsafe capability to the wrong resulting index and misses the actual index-zero exposure. This is HIGH finding H-2.

## 7. Array/tuple-spread findings

Direct, nested, readonly, returned, exported, indexed, and ordinary destructured spread scenarios covered by the fixtures pass. Two residual defects remain:

- Rest binding elements are treated as a single exact source index instead of a new suffix container, so `const [first, ...rest] = tuple` loses callable provenance through `rest[0]`.
- Conditional alternative spread sources are concatenated by the registration loop instead of modeled as alternative layouts.

Both are statically resolvable and security-relevant.

## 8. Class-expression and alias findings

Direct named/anonymous class expressions and ordinary aliases are covered. Class identity does not propagate through statically resolvable function returns, so class factories and constructor-return aliases bypass. Variable-bound class expressions inside namespaces are registered under an unqualified identifier, preventing a namespace-qualified alias from resolving its surface. These are grouped as HIGH finding H-3.

## 9. Override-resolution findings

Safe child overrides in the same member namespace are accepted, and unsafe inherited members without an override are normally rejected. The inheritance implementation uses one `declaredNames` set for both instance and static namespaces. Consequently, a safe static declaration suppresses an unsafe inherited instance member of the same name, and a safe instance declaration suppresses an unsafe inherited static member. Both probes produced zero findings. This is HIGH finding H-4.
