- Resolved architecture decisions: one adapter, one sealer, one bytea normalizer,
  no caller authority, no direct tables, no fallback/dual write, exact eight-input
  mapping, exact 12-column normalization, and no route activation.
- Evidence-gated: managed LOGIN/client, pooling/role behavior, driver bytea and
  timestamptz forms, Unicode parity, retry/timeout values.
- Product/route-gated: `in_progress` status, polling, UI lock, snapshot exposure.
- SQL-review-gated: full Authorization Context retrieval/consumption contract.
