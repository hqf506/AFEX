## Rollback decision checklist

- [ ] Has the request entered acquisition?
  - [ ] No: selector/route/UI rollback may send a later new request to legacy.
  - [ ] Yes: never invoke legacy for that logical request.
- [ ] Is the command acquired but not terminal?
  - [ ] Pause claims if necessary.
  - [ ] Diagnose and governed-resume the same command.
- [ ] Is the business transaction committed?
  - [ ] Return/recover through replay.
  - [ ] Do not delete or recreate the order.
- [ ] Is only delivery failing?
  - [ ] Pause worker/provider event type.
  - [ ] Retain and retry outbox evidence.
- [ ] Is database state committed?
  - [ ] Use reviewed forward fix; no automatic destructive rollback.
