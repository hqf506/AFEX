## `afex_core_runtime` disposition

Decision: `DEPRECATE_FROM_APPLICATION_RUNTIME_PATH`.

- The role remains in the database unless a separately reviewed lifecycle decision removes it.
- The application LOGIN receives no membership in it.
- It is not automatically approved for a worker or internal caller; any such use requires an independent contract.
- Its existing exact P2D.20 EXECUTE grant is not modified here. A future SQL design must inventory whether it remains necessary and either preserve it with rationale or revoke it through separately reviewed forward and rollback units.
- Existing Supabase-managed administrative membership is not touched without separate authority evidence.

## Future SQL unit redesign

The old LOGIN-plus-membership unit is superseded. Future design must separate:

1. Dedicated LOGIN creation and attribute normalization.
2. Exact-signature direct EXECUTE grant and all other privilege denials.
3. Function owner/body/search-path/signature and ACL attestation.
4. Existing `afex_core_runtime` grant disposition review.
5. Emergency LOGIN disablement and exact EXECUTE revocation.
6. Complete cleanup and post-cleanup read-only attestation.

No executable SQL is authorized or included here.
