# A2.3E Local Collector Execution Plan

Status: OPTIONAL — STATICALLY PREPARED, NOT EXECUTED

## Purpose and boundary

The collector inventories local repository/runtime metadata only. It does not contact Supabase, Vercel, PostgreSQL, or any network; read `.env` files; print environment values; execute SQL; install dependencies; or mutate Git. Its only write is a timestamped local evidence directory.

## Preconditions

1. Independently review the collector source and SHA-256.
2. Use Windows PowerShell 5.1 or PowerShell 7 without elevation.
3. Run from the proven `leather-fix-erp-clean` repository.
4. Confirm `git`, local Node, and local npm are available; absence/failure is fail-closed.
5. Confirm the evidence directory is local and excluded from any automatic publication workflow.

## Operator command

From the repository root, after approval:

`& .\database-reconciliation\core-v2\P2D\A2.3E-COLLECT-LOCAL-RUNTIME-METADATA.ps1`

This command is documented only and was not run in A2.3E.

## Evidence output

The script creates `database-reconciliation/core-v2/P2D/evidence/A2.3E-local-<UTC timestamp>/` containing exactly:

- `A2.3E-local-runtime-metadata.txt`
- `A2.3E-local-runtime-metadata.stderr.txt`
- `A2.3E-local-runtime-metadata-summary.txt`

The metadata contains repository path, branch, status count, package metadata, lock version, Next and Node declarations, local Node/npm versions, approved environment-name presence as `SET` or `MISSING`, selected config existence/hashes, PostgreSQL client package names, and runtime declaration locations. It never outputs environment values.

## Fail-closed behavior

The collector parses its own source and rejects prohibited network/provider/database commands and Git mutation/network subcommands. It fails when repository identity cannot be proven, a local metadata command fails, or evidence cannot be safely written. Failure evidence is retained, stderr receives the non-secret reason, the summary records `FAIL`, and the process returns nonzero. It requires no runner or administrator privilege.

## Review and disposition

Verify all three files exist, summary result is `PASS`, stderr is empty, environment entries contain only `SET`/`MISSING`, and no secret-like material exists. Hash the evidence before normalization. Do not rerun automatically after failure; review the retained failure first. Keep raw local evidence local unless separately approved for commit.
