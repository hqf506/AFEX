# A2.3F Minimal Supabase Operator Checklist

Collect only the fields below. Provider labels may change; if a field is absent, record `NOT_AVAILABLE` and use the escalation column. Never copy credentials, complete URLs, API keys, tokens, certificates, project secrets, or customer/tenant data.

| Dashboard page | Section | Safe field to copy | Hide/crop | Preferred capture | Evidence class | Gates |
|---|---|---|---|---|---|---|
| Project settings | Infrastructure/general | Project region, compute tier, PostgreSQL version | Project reference, organization identifiers | Typed text | DASHBOARD_VISIBLE | G6, G8 |
| Database settings | Connection limits/compute | Maximum and currently used connections, if visible | Hostnames and connection strings | Typed text | DASHBOARD_VISIBLE | G8 |
| Database settings | Network restrictions | Restriction enabled/state only | Addresses, allowlists, hostnames | Typed text | DASHBOARD_VISIBLE | G6 |
| Database settings | SSL/TLS | TLS required state | Certificate contents and connection strings | Typed text | DASHBOARD_VISIBLE | G6 |
| Connect/database settings | Direct connection | Availability and address-family support only | Username, password, hostname, database, full URL | Typed text | DASHBOARD_VISIBLE | G6 |
| Connect/database settings | Transaction pooler | Availability, mode label, port, IPv4/IPv6 support | Credentials, hostname, full URL | Typed text | DASHBOARD_VISIBLE | G3, G6, G8 |
| Connect/database settings | Session pooler | Availability, mode label, port | Credentials, hostname, full URL | Typed text | DASHBOARD_VISIBLE | G5, G6 |

## Documentation or support evidence

| Required fact | Required source | Gates |
|---|---|---|
| Dedicated custom LOGIN support | Provider support | G1 |
| SET-only membership with SET=true, INHERIT=false, ADMIN=false | Provider support | G2 |
| Explicit multi-statement transaction support and one-backend pinning | Provider support, then runtime test | G3 |
| `SET ROLE` and `SET LOCAL ROLE` behavior | Provider support, then runtime test | G4 |
| Backend sanitation and role reset on return | Provider support, then runtime test | G5 |
| Cancellation and abrupt-disconnect rollback | Provider support, then runtime test | G10 |
| Transaction advisory-lock support | Documentation/support, then runtime test | G11 |
| Prepared-statement restrictions | Current provider documentation | G7 |
| Recommended connection allocation and pool size | Provider support | G8 |

Unknown support or runtime facts must remain `UNKNOWN`, `SUPPORT_CONFIRMATION_REQUIRED`, or `RUNTIME_TEST_REQUIRED`; never infer them from dashboard availability.
