# A2.3 External Evidence Checklist

Status: safe metadata collection plan; never return credentials or full URLs

## Supabase dashboard

- Project reference in masked form and region.
- Compute tier and safe connection-limit metadata.
- Direct connection availability and IPv4 add-on/status if relevant.
- Transaction-pool and session-pool modes, host category and port numbers without username/password/full URL.
- Supavisor/PgBouncer transaction pinning, reset, prepared statement, cancellation and queue documentation/version.
- TLS modes and certificate-verification support.
- Network restrictions/allowlists and Vercel connectivity support.
- Supported custom LOGIN and SET-only membership model.
- Role/credential rotation and session termination mechanisms.

## Vercel project

- Production runtime and exact Node version.
- Function region/home region and whether route-specific placement is supported.
- Maximum duration, concurrency and scaling metadata for the proposed route.
- Direct outbound TCP support, DNS, IPv4/IPv6 behavior and egress restrictions.
- Environment scopes showing conceptual secret names only: Production, Preview, Development.
- Secret rotation/audit capability and who can view/change values.
- Deployment freeze/thaw and shutdown behavior relevant to pools.

## Production usage

- Safe current/peak database connection counts by application category.
- POS logical command rate, burst, duplicate and retry rates.
- Cold/warm invocation counts and latency from deployed region to database.
- Existing external cron, webhook, Edge Function, worker or command consumers not visible in repository.
- Incident/break-glass owners and support escalation path.

## Acceptable return format

Masked screenshots or text containing product setting names, modes, regions, ports, limits, versions and booleans. Redact passwords, keys, JWTs, full URLs, usernames if organizationally sensitive, certificate private material and connection strings. Do not paste environment-variable values.

## Required isolated proofs

- Same backend across explicit transaction.
- Pre/post role identity and cleanup after success.
- Cleanup after SQL error, rollback, timeout, cancellation, network loss and process termination.
- Cross-request connection reuse contamination test.
- Prepared statement and transaction-local setting behavior.
- Connection limit/backpressure and cold-start storm test.
- Credential rotation with old/new overlap followed by complete old-session revocation.

Evidence must identify environment, timestamp, component versions, test hash and reviewer. Production mutation is not authorized by this checklist.
