# A2.4A Hard-Disabled Adapter Skeleton

The server-only skeleton separates frozen input/raw-result aliases, a one-method transport port, inert lifecycle declarations, a hard-disabled factory, and a direct-import-only test fake. There is no concrete PostgreSQL transport.

The transport accepts exactly `AuthorizationContextAcquisitionInput`: authenticated actor, tenant, branch, idempotency key, correlation reference, canonical payload, fingerprint projection, and retention instant. It returns the existing adapter-owned `P2D20RawAcquisitionRow`. It has no generic SQL, connection, transaction callback, function-name, role-target, or credential surface.

`createHardDisabledTrustedAdapter()` takes no configuration and returns one frozen transport whose only operation fails with `CORE_V2_ADAPTER_DISABLED`. It does not inspect environment state or invoke caller callbacks. Inputs cannot enable it, and it has no legacy or service-role fallback.

Lifecycle names describe the future fail-closed protocol only. They execute no transition. The fake validates the exact raw-row shape, snapshots caller-owned values into immutable internal representations, returns fresh materialized copies, and records only call count and dispositions. It accepts copied failure metadata, retains no acquisition input, and is reachable only from the exact approved test allowlist—not from production barrels or arbitrary server modules.

The Core V2 public root remains unchanged. No application, route, component, hook, or feature flag imports this skeleton.
