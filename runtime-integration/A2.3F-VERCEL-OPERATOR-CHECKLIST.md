# A2.3F Minimal Vercel Operator Checklist

Collect names, labels, and aggregate values only. Do not expose environment values, URLs, tokens, project secrets, request payloads, or customer/tenant identifiers.

| Dashboard page | Section | Safe field to copy | Hide/crop | Preferred capture | Evidence class | Gates |
|---|---|---|---|---|---|---|
| Project settings | Functions/runtime | Production/function region, Node.js version, compute mode | Team/project identifiers | Typed text | DASHBOARD_VISIBLE | G6, G7 |
| Project settings | Functions/runtime | Maximum duration and memory | Unrelated settings | Typed text | DASHBOARD_VISIBLE | G8, G10 |
| Project settings | Networking | Static egress/private networking availability | IP addresses and identifiers | Typed text | DASHBOARD_VISIBLE | G6 |
| Project settings | Environment variables | Approved variable names and Production/Preview/Development presence | Every value and reveal control | Typed text only | DASHBOARD_VISIBLE | G9 |
| Observability | Function aggregates | Timeout frequency and sanitized connection-error counts | Logs, URLs, payloads, user/tenant IDs | Typed aggregate | DASHBOARD_VISIBLE | G10, G12 |
| Usage/analytics | Request aggregates | Request rate and available concurrency indicators | Project/user identifiers | Typed aggregate | DASHBOARD_VISIBLE | G8, G12 |
| Deployments | Rollback | Rollback availability | Commit authors and unrelated URLs | Typed text | DASHBOARD_VISIBLE | G12 |

## Documentation or support evidence

| Required fact | Required source | Gates |
|---|---|---|
| Outbound PostgreSQL TCP and IPv4/IPv6 support | Provider documentation/support | G6, G7 |
| Warm-instance connection reuse and lifecycle | Provider support, then runtime test | G5, G7 |
| Maximum/conventional per-instance pool size | Provider support | G8 |
| Maximum simultaneous instance behavior | Provider documentation/support | G8 |
| Connection handling during freeze, termination, cancellation, and redeployment | Provider support, then runtime test | G5, G10 |
| Secret encryption, rotation, revocation, scope, and redeployment workflow | Documentation plus organizational approval | G9 |
| Production log/correlation coverage | Dashboard plus operational review | G12 |

If a dashboard field is absent, record `NOT_AVAILABLE`; do not substitute an assumption. Provider claims remain distinct from future runtime-tested proof.
