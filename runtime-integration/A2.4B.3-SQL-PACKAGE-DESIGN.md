## Security boundary

The disposable LOGIN has no membership, ownership, elevated attribute, schema CREATE, P2D.20 EXECUTE, business-object grant, or generic function grant. The probe is fixed-signature, argument-free, owned by `afex_function_owner`, SECURITY DEFINER, and fixed to `pg_catalog`; it returns only caller/effective identity, backend PID, safe transaction identifier, and a constant.

The setup never embeds a password. Future execution must supply a short-lived password and finite validity outside Git. The attestation must run before the harness, and cleanup plus absence proof is mandatory after every run, including failed runs.
