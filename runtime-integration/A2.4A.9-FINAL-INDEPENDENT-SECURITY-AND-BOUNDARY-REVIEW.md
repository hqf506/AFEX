### HIGH — expression-wrapped indexed/container provenance is lost

- Path and lines: `scripts/check-core-v2-boundaries.mjs:433-447,591-605`.
- Issue: callable paths and container propagation do not unwrap parenthesized indexed expressions or propagate known container identities through sequence, conditional, and nullish expressions.
- Reproduced zero-finding cases: `(methods[0])()`, `(0, methods)[0]()`, `(flag ? methods : methods)[0]()`, and `(maybe ?? methods)[0]()` after `methods` is a known callable array.
- Violated contract: A2.4A.9 requires these statically resolvable indexed selections to be classified; every prohibited case must emit the stable rule.
- Required correction: normalize parenthesized expressions and conservatively merge container provenance across statically enumerable sequence/conditional/nullish branches while preserving dynamic-index limitations.
- Commit impact: blocks commit.

### HIGH — array/tuple spread provenance is lost

- Path and lines: `scripts/check-core-v2-boundaries.mjs:527-547`.
- Issue: `registerArrayCallables` handles functions, nested arrays, and direct callable aliases, but not `SpreadElement` sources.
- Reproduced bypass: a known `[f]` callable array spread into `second`, followed by `second[0]()`, produces zero findings.
- Violated contract: array/tuple spread was an explicit residual test and is statically resolvable.
- Required correction: copy indexed callable/value provenance through static spreads with deterministic index offsets and nested provenance; add safe string/acquire spread controls.
- Commit impact: blocks commit.

### HIGH — class expressions are not analyzed

- Path and lines: `scripts/check-core-v2-boundaries.mjs:701-752`.
- Issue: class-member collection is restricted to named `ClassDeclaration`; named and anonymous `ClassExpression` initializers are omitted.
- Reproduced bypasses: a named class expression exposing a static method and an anonymous class expression instantiated before an inherited-style instance call both produce zero findings.
- Violated contract: A2.4A.9 explicitly requires class expressions to be tested and every statically resolvable bypass to fail.
- Required correction: register variable-bound class expressions under their binding identity, including methods/getters/fields, static/instance distinction, construction, aliases, exports, and safe controls.
- Commit impact: blocks commit.

### HIGH — statically resolvable class aliases lose member surfaces

- Path and lines: `scripts/check-core-v2-boundaries.mjs:591-602`.
- Issue: identifier alias propagation copies only an exact callable path. It does not transfer callable/getter surface prefixes such as `Wrapper.*` and `Wrapper.prototype.*` to `Alias`.
- Reproduced bypass: `const Alias=Wrapper; Alias.getRunner()` produces zero findings when `Wrapper.getRunner` is a known static forbidden-capability method.
- Violated contract: namespace/class/import aliases are required to preserve statically resolvable provenance.
- Required correction: copy contained callable/value surfaces across aliases, preserving static/prototype identity and provenance; cover namespace and imported aliases without executing source.
- Commit impact: blocks commit.

### MEDIUM — safe class override inherits a false forbidden surface

- Path and lines: `scripts/check-core-v2-boundaries.mjs:701-735`.
- Issue: inheritance tests both `${Base}.prototype.` and the overlapping `${Base}.` prefix. A key such as `Base.prototype.getRunner` is correctly skipped under the first prefix when overridden, then incorrectly reprocessed as static-like `prototype.getRunner` under the second prefix.
- Failure scenario: a child that safely overrides an unsafe base method with `adapter.acquire` still emits a forbidden finding through an invented inherited path.
- Violated contract: safe-control and false-positive resistance requirements.
- Required correction: make static and prototype prefix matching mutually exclusive and apply override checks to the actual member name; add safe/unsafe override and multi-level tests.
- Commit impact: must be corrected with the HIGH findings before commit.
